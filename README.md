# استوديو ليل — Studio Layl
واجهة عربية RTL أولية مبنية بـ React + TypeScript + Vite.

## التشغيل
```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج
```bash
npm run build
```

## المزايا الحالية
- تصميم عربي RTL متجاوب للهاتف واللوحي وسطح المكتب.
- وضع ليلي ونهاري مع حفظ التفضيل في المتصفح.
- تحية تتغير حسب وقت اليوم.
- مكتبة أعمال مع البحث والتصنيفات والمفضلة.
- تشغيل معاينة صوتية عند توفير ملف صوتي حقيقي.
- نموذج طلب يجهز رسالة واتساب.
- إدارة محلية لإضافة الأعمال وحذفها.

## إعدادات ضرورية قبل النشر
- غيّر `WHATSAPP_NUMBER` داخل `src/App.tsx` إلى رقم الاستوديو بصيغة دولية دون علامة +.
- أضف ملفات MP3 إلى `public/audio`، ثم أدخل مساراتها في بيانات الأعمال أو لوحة الإدارة.
- الأعمال الحالية بيانات تجريبية وليست ملفات صوتية حقيقية.
- لوحة الإدارة محلية على المتصفح وليست محمية بتسجيل دخول ولا متصلة بقاعدة بيانات. لا تعتمد عليها للإدارة متعددة المستخدمين قبل بناء backend وصلاحيات.
